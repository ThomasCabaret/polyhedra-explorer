# Research results and certificates

These files are archived outputs. Run the commands in the [research README](../README.md) to produce a fresh run in `output/`.

| Artifact | What it records |
| --- | --- |
| [Tetrahedron](demo/) | Enumerated spherical map and numerical realization. |
| [K7 enumeration](k7-complete.json) | Triangular embeddings of the complete dual graph up to isomorphism. |
| [K7 numerical attempt](k7-realization-attempt.json) | Earlier optimization run with an unsuccessful geometry check. |
| [Three positive controls](validation-campaign.json) | Rational realizations generated from the known face maps of Szilassi, Mizhaev and Röst–Vígh. The geometry search derives symmetries from each map and samples planes independently of the reference coordinates. |
| [Genus 1 discovery certificate](discovery/9b4c587e1cb3c920ac499cd6.json) | A map enumerated through the generic K7 path, identified as Szilassi by isomorphism, and then realized and certified with exact rational arithmetic. |
| [Discovery campaign snapshot](discovery/campaign-snapshot.json) | Counters and bounds from the 21 November 2026 run. |
| [Genus 2 candidates](discovery/genus-2/) | All 24 genus 2 map fingerprints recorded in that snapshot, with their geometry attempts. |

The genus 2 artifacts are abstract maps with no certified realization. Some violate later geometric bounds in the [research note](../docs/finite_search_bounds.tex), including the exclusion of exactly five faces. Four records use JSON `null` for numeric fields that were undefined because the geometry solver did not handle holes. A failed numerical attempt leaves realizability open unless a proved obstruction applies.

The snapshot has 54,667,080 topological trials across genera 0–3 and zero valid genus 3 maps generated by that campaign. Its `topology_unique` counter is deduplicated by serialized map fingerprint. The separate positive controls certify geometry from the two known genus 3 maps.

Source credits for the control maps and known realizations are in [Data sources](../../../DATA_SOURCES.md) and in the [control catalog](../benchmarks/positive_controls.json).
